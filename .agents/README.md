# 🧠 Antigravity Multi-Agent Core: AI Workforce Operating System

Welcome to the coordination center of the **Multi-Agent** project. This directory contains the "soul" and "behavioral rules" of your AI agent team.

## 🏗️ System Architecture

The system is designed around a **Strategic Hierarchy**:

1. **[Roles](file:///.agents/roles/README.md)**: Defines 12 specialized roles, from **Gatekeeper** (Safety Gatekeeper) to **CTO** (Chief Technology Officer).
2. **[Rules](file:///.agents/rules/README.md)**: Operational rulesets (Clean Code, SOLID, DB Protection) ensuring every Agent stays aligned.
3. **[Workflows](file:///.agents/workflows/README.md)**: Automated collaboration workflows (Slash Commands) to solve tasks ranging from simple to enterprise-scale complexity.

## ⚖️ Mission & Ethics

All activities within this directory strictly adhere to **[RESPONSIBLE_AI.md](file:///home/rcvn/workspaces/AI/antigravity/RESPONSIBLE_AI.md)**.

### Golden Rules:
- **Human-in-the-Loop**: The Agent system operates autonomously, but critical decisions (such as Database Schema changes - DBS-001) require your direct approval (PO/CTO).
- **Transparency**: Every action taken by Agents is recorded in `task.md` and `walkthrough.md`.
