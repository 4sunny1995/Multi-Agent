## 🚦 Team Collaboration Protocol (Handoff)

Every Agent must adhere to the **Team Handoff Protocol**:
1. Read the input document from the preceding Agent.
2. Execute tasks according to strict Rules.
3. Publish output documents to designated storage paths.
4. Mark `[x]` in `task.md`.
